A. 端到端总览渐进式注册·先浏览后注册

游客可看清晰照片与完整资料；注册墙放在「想打招呼」时，认证墙放在「首次聊天前」（仅真人活体，不采集实名）。

flowchart TD
    Start([用户打开链接/广告点入]) --> Landing[落地页：练语言·遇见另一个世界的人]
    Landing --> Browse[游客免注册浏览-发现页/完整资料卡/破冰话题]
    Browse --> Match[匹配:语言互补优先]
    Match --> Pick[查看完整资料卡-清晰照片+资料-防搬运水印]
    Pick --> Want{想点赞/打招呼?}
    Want -->|继续逛| Match
    Want -->|是| RegWall[注册墙在此-手机/邮箱/第三方·30秒]
    RegWall --> AddPWA{引导添加到主屏幕?}
    AddPWA -->|是| Installed[已安装PWA·可接收推送]
    AddPWA -->|稍后| Browser2[浏览器内继续]
    Installed --> Profile
    Browser2 --> Profile
    Profile[快速建资料:母语/目标语/兴趣/意图] --> Hello[发起打招呼-双向·写开场白·可AI一键破冰]
    Hello --> Accept{对方接受?}
    Accept -->|未接受| Match
    Accept -->|是| VerifyGate[认证墙在此·聊天前-真人活体核验-不采集实名]
    VerifyGate --> Chat[进入聊天窗口]
    Chat --> Tools[使用翻译/纠错/朗读/语音/AI润色]
    Tools --> Deepen[关系深化:动态互动/视频通话]
    Deepen --> Retain([长期留存:语伴→朋友→缘分])

C. 渐进式注册三级漏斗

T0 游客免注册浏览 → T1 想打招呼时注册并弹出开场白编辑器 → T2 首次聊天前真人活体核验。

flowchart TD
    subgraph T0["T0 游客态-免注册"]
        A0([落地页]) --> A1[免注册进入发现/匹配]
        A1 --> A2[浏览完整资料卡-清晰照片+资料]
        A2 --> A3[看破冰话题/感受价值]
        A3 --> A4{想点赞/打招呼?}
        A4 -->|否,继续逛| A1
    end
    A4 -->|是| B0
    subgraph T1["T1 轻账号-打招呼时触发注册"]
        B0[注册:手机/邮箱/第三方] --> B1[验证]
        B1 --> B2{iOS用户?}
        B2 -->|是| B3[引导添加到主屏幕-解锁Push]
        B2 -->|否| B4[一键安装横幅]
        B3 --> B5
        B4 --> B5
        B5[快速建资料] --> B6[恢复动作:弹出开场白编辑器]
    end
    B6 --> C0{对方接受→准备进会话?}
    C0 -->|未接受| A1
    subgraph T2["T2 认证态-首次聊天前触发"]
        C0 -->|是| V2[真人活体核验-自拍-不采集证件实名]
        V2 --> V4{通过?}
        V4 -->|是| V6[授予真人认证标记]
        V4 -->|失败| V7[限权:可继续浏览引导重试]
        V6 --> Done
    end
    Done([进入聊天窗口])

D. 匹配 · 受保护的双向AI 破冰 · 防骚扰

任一方都能发开场白；首次接触需对方接受后才自由聊。AI 一键破冰降摩擦；男方每日 5 条配额防刷屏；开场白长期有效、不设倒计时。

flowchart TD
    M0([进入匹配页]) --> M1[算法排序:语言互补>兴趣>活跃度]
    M1 --> M2[展示资料卡:语言/兴趣/认证徽章/口音标签]
    M2 --> M3{用户操作}
    M3 -->|喜欢/打招呼| M4[写一条开场白·AI一键破冰可选]
    M3 -->|跳过| M1
    M3 -->|筛选| M5[按语言/水平/地区筛选] --> M1
    M4 --> Quota{男方免费账号?}
    Quota -->|是| Q1{今日配额还剩?}
    Quota -->|否·女方/已认证| Queue
    Q1 -->|有·每日5条| Queue
    Q1 -->|用完| Soft[提示:认证或明天再来] --> M1
    Queue[开场白进入对方待接受] --> W1{对方决定}
    W1 -->|接受| Chat([建立会话·开场白成首句])
    W1 -->|忽略| Soft2[静默忽略·不通知发送方]
    W1 -->|举报| Block[记录信号→风控]
    Chat --> Anti[进入前显示安全与反诈提示]

E. 聊天 · 语言工具护城河

翻译/纠错/朗读/语音/AI 破冰润色内嵌聊天；每条消息经内容审核与反诈扫描。

flowchart TD
    C0([进入聊天窗口]) --> C1[顶部:对方语言/口音/认证徽章]
    C0 --> Safe[首次会话横幅:切勿转账-涉钱即诈骗信号]
    C1 --> Send[发送消息]
    Send --> Tool{需要语言辅助?}
    Tool -->|翻译| TL[逐句翻译]
    Tool -->|纠错| TC[语法纠错/批改]
    Tool -->|发音| TP[TTS朗读]
    Tool -->|语音| TV[语音消息→转文字]
    Tool -->|AI| AI[AI破冰/润色]
    TL --> Flow
    TC --> Flow
    TP --> Flow
    TV --> Flow
    AI --> Flow
    Send --> Scan[实时内容审核+反诈扫描]
    Scan --> Risk{命中风险?}
    Risk -->|涉钱/外链/敏感| Warn[弹出反诈警示+一键举报]
    Risk -->|正常| Flow[消息送达]
    Flow --> Grow{关系升温?}
    Grow -->|是| Call[发起语音/视频-实时字幕]
    Grow -->|是| Moment[互相看动态/评论]
    Call --> Retain([语伴→朋友→缘分])
    Moment --> Retain
    Warn --> ReportFlow[举报→风控审核→封禁/申诉]

F. 反诈与举报闭环贯穿全局

跨国+语言+情感是电信诈骗重灾区，反诈体系必须 Day 1 就在。

flowchart LR
    Signal[风险信号来源] --> S1[消息扫描-涉钱/外链]
    Signal --> S2[用户举报]
    Signal --> S3[行为异常-群发/秒回/新号高频]
    S1 --> Q[风控队列]
    S2 --> Q
    S3 --> Q
    Q --> Judge{审核判定}
    Judge -->|确认违规| Ban[封禁/限权]
    Judge -->|存疑| Restrict[临时限制+二次认证]
    Judge -->|误报| Restore[恢复+记录]
    Ban --> Appeal[申诉通道]
    Restrict --> Appeal
