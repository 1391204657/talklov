# NiHello（你好 · Hello）

> 一款主打**中美语言交换 + 自然交友**的跨文化社交 PWA。
> 以「语言交换」为正当入口，「自然交友」做留存，约会是水到渠成的结果。

## 产品一句话
和母语者一起练语言，遇见另一个世界的人。

## 目标用户
- 🇺🇸 美国人（男性居多）：想学中文 / 了解中国文化 / 认识中国朋友
- 🇨🇳 中国人（女性居多）：想练英语 / 接触国际视野 / 认识海外朋友

## 关键设计原则（第一版就落地）
1. **语言优先做招牌，约会做结果** —— 避免劣质约会流量淹没真实用户。
2. **受保护的双向 + AI 降摩擦**（针对美中跨国调优，非纯 Bumble）—— 任何一方都能发起，但首次接触只能发**一条开场白、需对方接受**；用 **AI 一键破冰**消除女性语言焦虑，用**男方每日配额**防刷屏；跨国时差下**开场白长期有效、不设倒计时**。
3. **反诈 Day 1 就在** —— 跨国情感是诈骗重灾区，消息扫描 + 举报闭环。
4. **真人认证优先，实名暂缓** —— MVP 只做真人活体核验；中国实名/ICP备案/数据境内化作为将来开关。
5. **PWA 形态** —— 免上架、免抽成；用「添加到主屏幕」解锁 Web Push。

## 技术形态（规划）
- 前端：Next.js (React) + PWA
- 实时聊天：WebSocket；音视频：WebRTC（可接 Agora/LiveKit）
- 后端：Node/NestJS 或 Go；数据库：Postgres
- 翻译 / TTS / 语音转文字：云 API
- 支付：海外 Stripe/Apple Pay，国内微信/支付宝（合规主体）

## 可运行原型（web/）
一个能在浏览器点着走完 T0→T1→T2 全流程的真实原型（Next.js 16 + React 19 + Tailwind v4，PWA）。

**如何运行：**
```bash
cd web
npm install      # 首次运行需要
npm run dev      # 启动后打开 http://localhost:3000
```

**已实现的可点击流程：**
- 落地页 → 免注册浏览发现页（清晰照片 + **右下角防搬运水印**（不遮脸）+ 隐私分级遮挡）
- 打开资料 → 点「打招呼」触发**注册墙**（T0→T1）；**注册完成后自动回到该用户并弹出「开场白」输入框**，无需再点一次
- **开场白模式（受保护的双向）**：任一方先写一条开场白 → 进入对方「待接受」；接受后这句成为会话第一句。编辑器内置 **✨AI 一键破冰**（双语候选，点一下填入），男方免费每日配额 5 条（认证无限），跨国时差下开场白长期有效不倒计时
- 进入聊天前触发**真人认证墙**（T1→T2，大陆叠加实名）
- 聊天窗口：翻译 / 朗读(TTS) / **真实语音输入**（SpeechRecognition 转文字）/ **发送语音消息**（MediaRecorder 录音 + 可播放）+ **反诈拦截**（输入"转账"试试）
- **AI 助手**：✨AI 破冰话题（按对方兴趣生成开场白）、✨AI 润色（发送前把草稿改得更自然并给中英对照）
- **中文口音标签**：资料区分「普通话 Mandarin / 粤语 Cantonese」，用于日后精细匹配（如珊珊 Shan）
- 动态广场、AI 陪练、我的（含**照片可见范围**：公开 / 仅登录 / 仅认证 + **浅色/深色主题**）

> 语音输入 / 发送语音需在 Chrome / Edge 且允许麦克风权限；不支持的浏览器会给出友好提示。

## AI 接入说明（web/src/app/api/ai/route.ts）
- AI 调用在**服务端**完成，API key 不会进入浏览器。
- 供应商**可切换**：复制 `web/.env.example` 为 `web/.env.local` 并填入 key 即可启用真实模型。
  - OpenAI（大陆被墙，需代理）、DeepSeek（大陆可用）、通义千问 Qwen（大陆可用）均兼容。
- 未配置 key 时使用内置智能兜底，保证 demo 可跑。

## 接入真实后端（Supabase）
应用带**配置开关**：未配置时用离线 mock（demo 照常跑），配置后自动切换到真实 Auth + Realtime。

1. 在 [supabase.com](https://supabase.com) 新建项目。
2. 打开 **SQL Editor**，把 `supabase/schema.sql` 全文粘贴运行（建 4 张表 + RLS + Realtime + 触发器）。
3. 在 `web/.env.local` 填入（Project → Settings → API）：
   ```
   NEXT_PUBLIC_SUPABASE_URL=https://xxxx.supabase.co
   NEXT_PUBLIC_SUPABASE_ANON_KEY=eyJhbGci...
   ```
4. 开发期为省事可在 **Authentication → Providers → Email** 关闭 "Confirm email"（或配置 SMTP）。
5. 重启 `npm run dev`：注册/登录走真实邮箱密码，聊天走 **Supabase Realtime** 实时订阅。

> 表：`profiles`（1:1 auth.users）、`conversations`（会话，女方接受前为 pending）、`icebreakers`（开场白队列）、`messages`（文本/语音消息）。RLS 已配置：资料公开可读、会话/消息仅双方可见、消息仅在会话 accepted 后可发。
